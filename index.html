LumenPnP Config Tool

This tool helps you determine what you need to run your job on a LumenPnP.

  • Input the number of parts for each tape width from your BoM.
  • Use a lot of some parts? Set a priority to make sure they're in an auto feeder.
  • Rearrange strip feeders in the machine's work area.
  • Need a custom IC tray? Generate a 3D printable one using our web tool.
  • Import your Gerber or DXF file to check that everything will fit.
  • Add all needed parts to a cart on the Opulo webstore.
